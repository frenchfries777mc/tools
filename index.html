FRY SHEET

SPREADSHEET
수식 · 차트 · 엑셀 파일수식·그래프·표 AI자동 저장로그인 없이
엑셀처럼 표를 만들고 계산하는 스프레드시트예요. 엑셀 파일을 열고 저장할 수 있고, 몇 가지 기능을 더했어요.
  • SUM, IF, VLOOKUP 같은 함수 60여 개
  • 표를 고치면 바로 바뀌는 차트, 색 단계, 데이터 막대, 체크박스
  • 수식·그래프·표를 AI가 만들어 줘요. 짧고 정해진 형식이라 결과를 확인하고 바로 쓸 수 있어요
  • =AI("영어로 번역", A2)처럼 쓰면 칸마다 답을 채워요. 표에 대한 질문·요약도 되지만 답이 틀릴 수 있어요
  • 아이패드에서도 손가락으로 범위 선택과 채우기

블록 코딩

BLOCK HTML

JAVASCRIPT BLOCKS
블록 → HTML 파일한 블록씩 실행예제 5개로그인 없이
자바스크립트를 블록으로 조립해 웹페이지를 만들고, 완성되면 HTML 파일로 받아요. 만든 페이지는 어디서든 열려요.
  • 제목, 버튼, 입력칸, 그림판 같은 화면 블록
  • 누르면, 키를 누르면, 초마다 같은 이벤트와 조건, 반복, 변수, 함수
  • 바로 보이는 미리보기와 읽기 쉬운 HTML 코드
  • AI 도우미(시험 기능)로 블록 초안을 받을 수도 있어요. 거친 초안이라 직접 확인하고 고쳐야 해요

발표 자료

FRY SLIDES

PRESENTATIONS
슬라이드 편집PPTX 파일발표 모드로그인 없이
글자를 눌러 바로 고치고, 테마와 레이아웃을 골라 발표 자료를 만들어요. 바로 발표하거나 파워포인트 파일로 받아요.
  • 주제를 쓰면 AI가 초안을 써 주는 시험 기능도 있어요. 거친 초안이라 내용과 사실은 직접 확인하고 고쳐야 해요
  • 글자를 눌러 바로 고치고, 슬라이드마다 다시 쓰기·더 짧게·더 자세히
  • 테마 6가지, 레이아웃 7가지, 끌어서 순서 바꾸기
  • 전체 화면 발표, 고칠 수 있는 PPTX 파일, PDF 인쇄

실험실

FRY LAB

SCIENCE & MATH LAB
실험 9가지기록·그래프·CSV탐구 과제로그인 없이
슬라이더를 움직이면 바로 바뀌는 중고등 과학·수학 실험실이에요. 값을 재서 표에 기록하고, 그래프로 규칙을 찾아요.
  • 함수 그래프, 확률, 삼각함수, 포물선 운동, 진자, 용수철, 빛의 굴절, 물결파 간섭, 옴의 법칙
  • 끌어서 바꾸는 시뮬레이션과 실시간 측정값, 해 볼 만한 탐구 과제
  • 기록한 표로 그래프와 추세선을 그리고 CSV로 내보내기
  • AI 도우미(시험 기능)에게 원리를 물어볼 수 있어요. 답이 틀릴 수 있으니 직접 확인해요

Block HTML object library ("Objects" picker) - sources and licenses
===================================================================

The pictures in objects-lib.js come from two sources. Each item in that file
names its source ("own" or "fluent").

1. "own" - original illustrations
---------------------------------
Drawn by hand as SVG for Block HTML (Frenchfries777 Tools). Use them freely in
the pages you make with Block HTML.

2. "fluent" - Fluent Emoji (flat style) by Microsoft
----------------------------------------------------
Source: Microsoft Fluent UI Emoji, https://github.com/microsoft/fluentui-emoji
Taken from the npm package @iconify-json/fluent-emoji-flat version 1.2.6
(package.json "license": "MIT"; info.json: author Microsoft Corporation,
license MIT, https://github.com/microsoft/fluentui-emoji/blob/main/LICENSE).
A selection of 152 icons is included unchanged, each wrapped in an <svg> tag.
